# Revision Routers Lab (Cisco Packet Tracer 8.2.2)

File: `revision-routers.pkt`

- 13 Cisco 1841 routers, 7 Cisco 2960 switches, 12 PCs
- OSPF process 1, area 0, on 9 routers
- HSRP group 5 (virtual IP 190.170.1.50) on 2 routers
- DHCP pools on 4 routers
- NAT with an inside/outside setup, a standard ACL and a NAT pool on one edge router, plus default routes to the outside
