# Mini Project: DHCP, ACL, OSPF and Redundancy (Cisco Packet Tracer 8.2.2)

File: `mini-project.pkt`

- OSPF process 1, area 0, on all 7 routers
- HSRP group 5 (virtual IP 200.200.200.50) on 2 routers
