# Network Labs
Packet Tracer 8.2.2 and GNS3 2.2.59 lab files with short write-ups. Each folder says what was built and what it shows. Open `.pkt` files with Cisco Packet Tracer 8.2.2 or newer.

| Lab | Tool | Main topics |
|---|---|---|
| 01 Graduation project | Packet Tracer | VLANs, OSPF, HSRP, ACLs, IPsec tunnel, VoIP, IoT |
| 02 Routing and redundancy | Packet Tracer | OSPF, HSRP, DHCP, NAT, ACL |
| 03 Switching and VLANs | Packet Tracer | VLANs, trunks, VTP, router-on-a-stick |
| 04 BGP | GNS3 | multi-AS topology, iBGP and eBGP, route-map |
| 05 BGP ISP scenario | GNS3 (project file and startup configs) | eBGP and iBGP, two ISPs and a customer, OSPF core, route-maps |
| 06 OSPF multi-area | GNS3 (project file and startup configs) | OSPF areas 0, 23, 45, 67, 78, route redistribution |

Folders 04, 05 and 06 include the router startup configurations in a `configs/` folder.
